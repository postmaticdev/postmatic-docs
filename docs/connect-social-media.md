# Cara Menghubungkan Media Sosial

Dokumen ini menjelaskan draft langkah untuk menghubungkan akun media sosial ke Postmatic.

## Langkah-langkah

1. Buka menu integrasi atau koneksi platform di Postmatic.
2. Pilih platform media sosial yang ingin dihubungkan.
3. Klik tombol untuk memulai proses koneksi.
4. Login ke akun media sosial yang dipilih.
5. Berikan izin akses yang diminta.
6. Kembali ke Postmatic dan pastikan status akun sudah terhubung.

> [GAMBAR: Tambahkan screenshot menu koneksi platform.]

> [GAMBAR: Tambahkan screenshot halaman izin akses media sosial.]

## Catatan

Pastikan akun media sosial yang digunakan memiliki akses admin atau permission yang sesuai agar proses koneksi berhasil.
