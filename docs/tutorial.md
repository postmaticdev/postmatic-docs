# Cara Menggunakan Postmatic

Halaman ini adalah ringkasan alur penggunaan Postmatic dari awal sampai konten siap dipublikasikan.

## Alur dasar penggunaan

1. Siapkan akun media sosial yang akan digunakan.
2. Hubungkan akun media sosial ke Postmatic.
3. Buat konten baru melalui fitur AI atau upload file.
4. Atur jadwal publikasi konten.
5. Cek hasil prompt, preview konten, dan status publikasi.
