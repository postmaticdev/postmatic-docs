# Detail Pengulangan Konten

Content Repetition digunakan untuk membuat konten yang dipublikasikan berulang berdasarkan pola tertentu.

## Langkah-langkah

1. Buka konten yang ingin dibuat berulang.
2. Aktifkan opsi pengulangan konten.
3. Pilih pola pengulangan, misalnya harian, mingguan, atau bulanan.
4. Tentukan tanggal mulai dan tanggal selesai jika diperlukan.
5. Simpan pengaturan.
6. Cek daftar jadwal untuk memastikan konten berulang sudah dibuat.
