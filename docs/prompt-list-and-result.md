# Daftar Prompt dan Hasil

Halaman ini berisi draft untuk menjelaskan daftar prompt dan hasil konten yang dibuat dari prompt tersebut.

## Melihat daftar prompt

1. Buka halaman prompt atau riwayat AI.
2. Pilih prompt yang ingin dilihat.
3. Cek detail instruksi, tanggal dibuat, dan status hasilnya.

> [GAMBAR: Tambahkan screenshot daftar prompt.]

## Melihat hasil prompt

1. Klik salah satu prompt dari daftar.
2. Review hasil konten yang dibuat.
3. Edit hasil jika diperlukan.
4. Gunakan hasil tersebut untuk draft konten atau jadwal publikasi.

> [GAMBAR: Tambahkan screenshot detail hasil prompt.]

## Contoh format prompt

```text
Buat caption Instagram untuk promosi produk baru.
Target audiens: pemilik bisnis kecil.
Gaya bahasa: santai dan persuasif.
Tambahkan call to action untuk menghubungi admin.
```
