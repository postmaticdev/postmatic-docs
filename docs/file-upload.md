# Detail Upload File

Fitur File Upload digunakan untuk menambahkan file pendukung yang akan dipakai dalam proses pembuatan atau publikasi konten.

## Langkah-langkah

1. Buka halaman pembuatan konten atau media library.
2. Klik tombol upload file.
3. Pilih file dari perangkat Anda.
4. Tunggu sampai proses upload selesai.
5. Pastikan file muncul di daftar media atau lampiran konten.

> [GAMBAR: Tambahkan screenshot tombol upload file.]

> [GAMBAR: Tambahkan screenshot file yang berhasil diunggah.]

## Catatan

Gunakan format file yang didukung oleh Postmatic. Jika upload gagal, cek ukuran file, format file, dan koneksi internet.
