# Detail Tutorial Membuat Konten dengan AI

Fitur Build with AI digunakan untuk membantu membuat draft konten berdasarkan instruksi atau prompt yang Anda masukkan.

## Langkah-langkah

1. Buka menu pembuatan konten di Postmatic.
2. Pilih opsi **Build with AI**.
3. Masukkan instruksi konten, target audiens, gaya bahasa, dan tujuan konten.
4. Klik tombol generate atau buat konten.
5. Review hasil konten yang dibuat AI.
6. Edit teks jika diperlukan sebelum dijadwalkan atau dipublikasikan.

## Tips prompt

- Tulis tujuan konten dengan jelas.
- Sertakan platform tujuan, misalnya Instagram, Facebook, atau LinkedIn.
- Jelaskan gaya bahasa yang diinginkan, seperti formal, santai, informatif, atau promosi.
