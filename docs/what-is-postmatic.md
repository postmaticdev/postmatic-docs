# Apa itu Postmatic?

Postmatic adalah platform untuk membantu proses pembuatan, penjadwalan, dan publikasi konten media sosial dari satu tempat.

## Fungsi utama

- Mengelola koneksi akun media sosial.
- Membuat draft konten dengan bantuan AI.
- Mengunggah file pendukung untuk kebutuhan konten.
- Menjadwalkan konten agar terbit sesuai waktu yang ditentukan.
- Menggunakan pengulangan konten untuk kebutuhan publikasi rutin.

## Kapan menggunakan Postmatic?

Gunakan Postmatic ketika Anda ingin membuat alur kerja konten yang lebih teratur, mulai dari pembuatan ide, penyusunan konten, sampai penjadwalan publikasi.
